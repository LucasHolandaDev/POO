# 📚 Atividades de Programação Orientada a Objetos
Neste repositório, serão desenvolvidas as atividades propostas na disciplina de Programação Orientada a Objetos (POO) do IFRN – Campus Natal Central, utilizando a linguagem Java e Python.

O objetivo é colocar em prática os conceitos estudados em aula, aprimorar meus conhecimentos em Java/Python e acompanhar minha evolução ao longo da disciplina. 🚀

    💡 Este repositório também servirá como um registro da minha jornada de aprendizado e evolução na programação.
